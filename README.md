# Student Gradebook (MySQL)

A Python CLI application that manages student grades using a MySQL database. This project demonstrates database aggregations, filtering, and sorting.

## Features
- Add students with their name, score, and subject.
- View all students in the database.
- Filter students by subject.
- Calculate the overall class average using SQL `AVG()`.
- Find the top scorer using SQL `ORDER BY` and `LIMIT`.

## Tech Stack
- Python 3
- MySQL
- `mysql-connector-python`, `python-dotenv`
